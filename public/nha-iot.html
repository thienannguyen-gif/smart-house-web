Kết nối mạch thật

Trang gọi API /api/devices trong project Next.js (chạy bằng npm run dev hoặc đã deploy lên Vercel). Nếu trang này nằm trong thư mục public của chính project đó thì để trống địa chỉ. Trang mở bên trong Claude bị chặn kết nối ra ngoài, nên hãy mở file HTML bằng Chrome.
